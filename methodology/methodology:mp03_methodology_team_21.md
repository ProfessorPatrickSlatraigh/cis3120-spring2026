As the integrator, this project used SEC EDGAR filings to identify corporate location-related events across two industries: Financial Services and Travel & Hospitality. Our team developed a multi-stage pipeline that collected filings using industry-specific ticker lists and keyword phrases, filtered candidates using ticker and fallback text matching, extracted events through an LLM-based classifier, geocoded company locations, and visualized results with an interactive Folium map. We also performed window-length analysis at 30, 60, and 90 days to compare event coverage and retrieval stability. One major challenge was inconsistent ticker metadata across EDGAR filings, which required fallback matching using filing display names to improve candidate filtering accuracy.

For the Financial Services methodology, I implemented and tested the pipeline helper functions, expanded the Financial Services EDGAR search phrases, and ran 30/60/90-day window trials. The workflow searched SEC EDGAR filings using Financial Services tickers and industry-related phrases, filtered filings by ticker matches, extracted candidate location events using the Anthropic model, and attempted geocoding for final event mapping. I also added fallback ticker filtering logic using filing display names because many SEC filings returned missing ticker metadata. Some limitations included transient SEC server errors, low event counts, and invalid or incomplete filing location information during extraction and geocoding.

As the Travel and Hospitality Pipeline Lead, I was responsible for choosing company tickers, extending the search phrases, and running the SEC 8K pipeline. The ticker list included major travel and hotel companies to capture location related business activity across the different areas. I added the extended search phrases because they matched the language commonly used in Travel and Hospitality filings. I also tested the different time windows as instructed but the pipeline did not produce any final geocoded events after the ticker filtering. The results indicate that the companies may file fewer location specific 8K events than expected. Based on the limited results, our results still demonstrated the importance of testing multiple window sizes and documenting pipeline limitations clearly.
